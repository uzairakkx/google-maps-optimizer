# Engineering rules

- This repository is being built milestone by milestone.
- Do not add product features outside the current milestone.
- Do not create fake Google, competitor, ranking, review, or dashboard data.
- Keep API routes, application logic, persistence, and provider adapters separate.
- Tenant-sensitive queries must be scoped on the backend when tenancy is introduced.
- Do not add secrets to source control or logs.
- Before completing a milestone, run the relevant tests, lint, type checks, and build checks.
